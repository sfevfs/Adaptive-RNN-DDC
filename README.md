# Adaptive-RNN-DDC

This code was developed by the authors of the manuscript "Delay-Aware Budgeted Temporal CSI Feedback for FDD Massive MIMO Systems."

Adaptive-RNN-DDC combines an ALC-RNN open-loop predictor, a two-stage future-slot controller, Low/High/Refresh recovery experts, and delay-aware inference calibration. This package contains the model, training, evaluation, and configuration code for the reported three-route method.
